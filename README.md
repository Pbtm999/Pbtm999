## About me

I'm a software developer with a strong Computer Science background and a particular interest in **software engineering and systems**.

I enjoy working across different levels of the stack, from backend and web applications to software architecture, compilers, operating systems and lower-level programming.

My academic and personal projects have involved areas such as:

- software architecture and design patterns;
- compilers and programming languages;
- algorithms and data structures;
- artificial intelligence and search algorithms;
- distributed and backend systems;
- databases and data processing;
- Linux and containerized environments.

I'm currently expanding my knowledge of **Rust, Linux and database internals**, with the goal of building more systems-oriented projects.
